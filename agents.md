# Financial copilot
## Clean and tidy history
Do not commit vast amounts of work at once. Create one git commit as soon as each task in `tasks.md` is finished (do not ask first). Use branches if necessary.
It must always be possible to checkout the project and keep developping on another machine. Files that are not necessary for that (e.g. because they are automatically generated) should be in gitignore. 
#
Project principles are in [the constitution](.specify/memory/constitution.md). Read that file before changing specs, plans, tasks, or application code.
